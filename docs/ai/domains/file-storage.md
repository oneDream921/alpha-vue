# 文件存储

## 术语

| 术语 | 含义 |
|------|------|
| 文件元数据 | 文件名、对象键、大小、类型、访问地址等记录，不含二进制内容 |
| 存储提供者 | 对象存储实现边界，可由本地存储或 MinIO 提供 |
| 私有访问 | 通过短期签名内容地址获取文件，而非匿名对象读取 |

## 流程与规则

- 上传前校验扩展名、MIME、图片签名、大小、文件名和安全路径；对象键使用 UUID。
- 数据库只保存文件元数据和访问地址，不保存二进制内容。
- 默认私有访问。仅明确启用公开访问时才允许返回公开对象 URL；头像上传使用当前登录用户身份且仅接收图片格式。
- 删除顺序为先删除存储对象，再软删除元数据，避免记录已删除但对象残留。
- 文件上传、存储切换和访问链接不得泄漏密钥、令牌或上传正文至日志和审计记录。

## 字段语义

| 字段/状态 | 含义 |
|-----------|------|
| `publicUrl` | 当前可访问地址，私有文件时为短期签名内容地址 |
| `FILE_PUBLIC_ACCESS` | 明确开启后才允许匿名公开读取 |
