# Alpha Vue v0.1.0

## 发布内容

- 提供登录、Bearer 鉴权、RBAC 管理、用户密码重置、个人资料与头像裁剪。
- 提供 MySQL、Redis、Flyway、MinIO 文件存储、审计日志和开发环境 Knife4j。
- 发布前已完成真实 Docker Compose、Flyway、登录鉴权、上传预览删除与管理端回归验收。

## 回滚步骤

1. 停止新版本应用，部署上一稳定 Git tag 或镜像。
2. 保留 MySQL 数据和 `flyway_schema_history`；不得删除或改写已发布迁移。
3. 如需回滚数据，从发布前备份恢复 MySQL，并核对 Redis 会话和 MinIO 对象一致性。
4. 对回滚版本执行健康检查、登录、鉴权和文件上传 smoke test。
