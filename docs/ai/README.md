## 维护约定

- **domains/**：业务语义（WHAT/WHY）；禁止类路径、端口、构建命令
- **services/<名>/**：单仓实现与启动（HOW）；前端/后端各占一名
- **contracts/**：跨仓或前后端边界格式
- 落盘前三问：去掉类名/端口/命令还成立？→ domains；边界格式？→ contracts；单仓 HOW/启动？→ services
- 禁止在 `docs/ai/` 下自建未约定的第四层目录
