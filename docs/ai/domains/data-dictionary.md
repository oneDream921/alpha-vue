# 数据字典

## 术语

| 术语 | 含义 |
|------|------|
| 字典类型 | 全局唯一的可运营枚举分类 |
| 字典项 | 隶属于一个字典类型的展示标签和值 |
| 业务读取 | 已登录业务模块读取启用字典项的只读能力 |

## 流程与规则

- 字典类型与字典项独立建模。类型编码创建后不可修改；同一类型内未删除字典项的值必须唯一。
- 字典项值是字符串，可表达文字状态或数字枚举。首期允许同一类型存在多个默认项。
- 删除使用逻辑删除。删除类型前必须先删除其所有未删除字典项。
- 业务读取只返回启用类型下的启用字典项，并按排序值升序；不返回备注、审计字段或管理状态。
- 管理 CRUD 需要 `system:dict:*` 权限并记录操作审计；业务读取要求登录但不要求字典管理权限。

## 字段语义

| 字段/状态 | 含义 |
|-----------|------|
| `typeCode` | 全局唯一且不可变的类型编码 |
| `label` | 展示给用户的文本 |
| `value` | 业务使用的字符串枚举值 |
| `sortOrder` | 字典项升序展示顺序 |
| `isDefault` | 默认项标识，不要求在类型内唯一 |
| `status` | 启用或停用；停用项不可被业务读取 |
