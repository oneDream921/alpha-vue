# 参数配置

## 术语

| 术语 | 含义 |
|------|------|
| 参数配置 | 可由管理端维护的业务配置键值记录 |
| 基础设施配置 | 服务、数据库、Redis、存储和认证等运行环境参数 |

## 流程与规则

- 参数配置仅作为持久化的业务数据源；新增、修改或删除不会隐式改变 Spring、认证、Redis、存储或上传等运行参数。
- 不得将密钥、密码、令牌或基础设施配置写入参数配置；它们仍由受控环境配置提供。
- 配置键需保持业务语义，并排除 `spring.`、`server.`、`datasource.`、`redis.`、`minio.`、`sa-token.` 等基础设施前缀及敏感字段名。
- 配置的写操作需要 RBAC、审计和软删除语义。

## 字段语义

| 字段/状态 | 含义 |
|-----------|------|
| `configKey` | 业务配置键；在未删除记录中唯一 |
| `configValue` | 业务配置值；不承担密钥托管 |
| `description` | 配置用途说明 |
