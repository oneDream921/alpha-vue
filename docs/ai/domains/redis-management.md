# Redis 运维

## 术语

| 术语 | 含义 |
|------|------|
| Redis 运维台 | 受 RBAC 和审计保护的 Redis 元数据查询与单键删除能力 |
| `SCAN` | 以游标增量遍历键空间的 Redis 命令 |
| 敏感键 | 验证码、会话、令牌、密码、密钥或凭据相关键 |

## 流程与规则

- 键查询使用带上限的 `SCAN` 游标分页，可按前缀和关键词筛选；不使用 `KEYS`。
- 可查看键名、分类、类型、TTL、大小估计和值预览。全局脱敏开启时不展示值；敏感键始终脱敏，且不反序列化 Redis 对象。
- 仅允许删除单个指定键。删除会影响会话或验证码等运行状态，前端必须二次确认并记录审计。
- 禁止 `FLUSHDB`、`FLUSHALL`、任意键写入和批量删除。

## 字段语义

| 字段/状态 | 含义 |
|-----------|------|
| `cursor` | 不透明的 `SCAN` 游标；`0` 表示遍历结束 |
| `count` | 单次查询上限，取值 1--100 |
| `valueTruncated` | 值预览已截断或因脱敏不可完整展示 |
