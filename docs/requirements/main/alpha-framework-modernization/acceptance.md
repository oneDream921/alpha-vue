# Alpha Vue 框架现代化验收方案

## 1. 验收规则

1. 自动化验证由执行模型完成并提供命令与结果。
2. 人工验收由用户完成，“结果”列保持空白，直到用户实际确认。
3. 一个门禁未通过时，只允许修复当前阶段问题，不自动开始下一阶段。
4. 阶段内采用针对性验证，阶段收口时执行完整验证。
5. 涉及登录、权限、会话、文件和运维操作时，必须包含真实 HTTP 或浏览器验证。
6. 任何敏感信息泄露、跨 client 误下线、数据破坏或不可回滚迁移均为阻断问题。

## 2. 通用自动化验证

具体命令应以项目实际脚本为准。当前推荐基线：

```bash
# 后端
./mvnw test
./mvnw package

# 前端
pnpm typecheck
pnpm test
pnpm lint
pnpm format:check
pnpm build

# 部署配置
docker compose config
```

若项目约定使用指定 Maven 安装，则统一使用：

```bash
/Users/mac/Documents/my-develop-tool/maven/apache-maven-3.9.11/bin/mvn test
/Users/mac/Documents/my-develop-tool/maven/apache-maven-3.9.11/bin/mvn package
```

不得通过跳过测试、关闭 lint 或放宽类型检查来获得通过结果。
